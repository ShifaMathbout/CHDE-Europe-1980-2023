# CHDE-Europe-1980-2023
R scripts and supporting materials for analyzing Compound Hot and Dry Events (CHDEs) across Europe (1980–2023) using E-OBS v30.0e climate data.

This repository contains the R scripts used to process and analyse the E-OBS v30.0e dataset. The E-OBS data are not included in the repository due to redistribution restrictions.

Users can download the data directly from the Copernicus Climate Data Store:

https://cds.climate.copernicus.eu/datasets/insitu-gridded-observations-europe R scripts for detecting, analysing, and mapping Compound Hot and Dry Events (CHDEs) across Europe from 1980–2023
